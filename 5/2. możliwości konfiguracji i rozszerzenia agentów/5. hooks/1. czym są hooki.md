Hooki dają możliwość podpięcia własnych zadań w reakcji na zdarzenia agenta llm.


Po co używać:
Bezpieczeństwo => tool - blokada niebezpiecznej komendy, ochrona przed niektórymi atakami prompt injection
Obserwowalność => logowanie - tooli, koszta tokenów
Automatyzacja => uruchomienie testów, uruchomienie lintera, uruchomienie prettiera
Extensionability => wzbogacanie prompta użytkownika; filtrowanie, specjalny sposób prezentacji odpowiedzi
RAG => wzbogacanie prompta o dokumenty korporacyjne
