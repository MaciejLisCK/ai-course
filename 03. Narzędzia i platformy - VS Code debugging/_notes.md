1. w vs code otworzyć chat, kliknąć w ikonę koła zębatego, wybrać "Show chat debug view", "Show agent debug logs"
2. zrobić zapytanie "w czym pić herbatę"
3. pokazać debug logs:
    1. dashboard
    2. agent flow chart
4. pokazać chat debug:
    1. pobranie modeli "modelList"
    2. generowanie tytułu
    3. generowanie progressMessages
    4. pokazać "W czym pić herbate" => "panel/editAgent"
