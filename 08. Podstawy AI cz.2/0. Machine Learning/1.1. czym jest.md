# Uczenie maszynowe (Machine Learning)
Sposób tworzenia modeli, które uczą się na danych, zamiast mieć zaprogramowane algorytmy, ręcznie reguły.


## Pełny przegląd ML
1. Mamy dane – zbiór obserwacji.
2. Tworzymy program - przyjmuje obserwację, przechodzi przez model (ma parametry które można dostosować), zwraca wynik
3. Trenujemy model - przepuszczamy dane przez model i na podstawie uzyskanych wyników dostosowujemy jego parametry.
    - model generuje wynik,
    - porównujemy go z oczekiwanym wynikiem lub innym kryterium,
    - obliczamy, jak bardzo model się pomylił,
    - dostosowujemy parametry tak, aby w przyszłości uzyskiwał lepsze wyniki.
4. Wnioskowanie (inferencja) - przepuszczamy nową obserwację i mamy wynik
