Czym jest Machine Learning

    Powiedzieć o tym że uczenie maszynowe jest wtedy kiedy mamy duży zbiór danych puszczamy te dane i trenujemy model żeby był jak najlepszy że dane i żeby jeśli dajemy najlepiej o uogólniał dane jeśli damy nową próbkę to żeby ta nowa próbka jak najlepiej była rozpoznana


Podział
    - nadzorowane
    - nienadzorowane
    - półnadzorowane
    - samonadzorowane

Generalizacja
Overfitting

Powiedzieć o tym jak trener model się trenuje na danych to znaczy że te dane go zmieniają model żeby jak najlepiej był wpasowany ten model dodanych ale generalizował a nie overfitował

Typowe zadania ML:
    - regresja
    - klasyfikacja
    - klastryzacja
    - redukcja wielowymiarowości
