# proces wnioskowania/działania
z = w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ + b
p = σ(z) = sigmoid(z) = 1 / (1 + e⁻ᶻ)
ŷ = 1, jeśli p ≥ 0,5; w przeciwnym razie ŷ = 0

# proces uczenia
modyfikacja wag i biasu tak, aby zmalała strata, która ocenia zgodność przewidywanych
prawdopodobieństw z prawdziwymi klasami

# struktura wiedzy po nauczeniu
liczby zmiennoprzecinkowe — wagi (w₁, w₂, ..., wₙ) i bias (b)
